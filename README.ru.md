## Что нового в v3.0 — RAG-интеграция удалённой базы знаний

Прямое потребление корпоративных / командных / личных баз знаний внутри редактора WPS: запрос → автопоиск → сборка контекста → ответ со ссылками на источники, с возможностью загрузить оригинал одной кнопкой.

- **Двойной режим аутентификации** (JWT пользователь / HMAC приложение), учётные данные шифруются AES-GCM
- **Многоисточниковая ретривал-пайплайн** (`services/kb`): переписывание → пакетный поиск → дедупликация → реранжирование → промпт с цитатами
- **Полоса цитат с загрузкой оригиналов**, источники типа документ / структурированный / вектор / Office различаются визуально
- **Самовосстановление при недоступности**: при удалении KB или отзыве прав кэш сбрасывается тихо — больше никаких красных "search_batch HTTP 403"
- **Один флаг для отката**: `kbRemoteIntegration` мгновенно отключает весь RAG-пайплайн

Полные примечания к релизу: [RELEASE_NOTES_v3.0.md](RELEASE_NOTES_v3.0.md)

## 🤖 Документ-агент (MCP) — позвольте внешним ИИ-агентам читать и писать ваши документы WPS

Chayuan поставляет **локальную службу документ-агента MCP (Model Context Protocol)**, которая открывает **26 инструментов** для чтения, поиска, замены, комментирования, вычитки и retrieval по базе знаний в ваших документах WPS как стандартную конечную точку **Streamable HTTP MCP**. Любой агент с поддержкой MCP — **Claude Code, OpenAI Codex, Cursor, Hermes, OpenClaw, Cline** — может указать на один URL и работать прямо внутри вашего документа WPS: открывать его, читать основной текст, отмечать опечатки как комментарии, пакетно заменять текст, делать перекрёстную вычитку нескольких документов.

- **Без аутентификации:** слушает только на `127.0.0.1` — localhost является границей доверия; для подключения нужен только URL (без токена / команды / stdio).
- **Полностью офлайн:** sidecar расположен рядом с WPS; документы и ключи никогда не покидают вашу машину — подходит для офлайн / интранет / изолированного (air-gapped) развёртывания.
- **Автозапуск при установке:** установщики регистрируют системный автозапуск на уровне ОС (Windows `HKCU\…\Run` / macOS LaunchAgent / Linux systemd --user); Node.js не требуется.
- **26 инструментов** охватывают статус документа / запуск / открытие / метаданные / чтение абзацев и фрагментов / поиск / замену / вставку / комментарии / пакетную запись / создание / сохранение / рассекречивание и восстановление / retrieval по базе знаний / проверку орфографии и грамматики (как комментарии или прямые правки текста) / поиск и экспорт ассистента. Полный список: [docs/mcp-connection.md](docs/mcp-connection.md).

### Подключение в одну строку (работает для любого MCP-агента)

Конечная точка: `http://127.0.0.1:62588/mcp`  ·  Проверка состояния: `GET http://127.0.0.1:62588/healthz` (ожидается `online`).

### Claude Code
```bash
claude mcp add --transport http chayuan-wps http://127.0.0.1:62588/mcp
```
или `.mcp.json`:
```json
{ "mcpServers": { "chayuan-wps": { "url": "http://127.0.0.1:62588/mcp" } } }
```

### OpenAI Codex (codex CLI) — `~/.codex/config.toml`
```toml
[mcp_servers.chayuan-wps]
url = "http://127.0.0.1:62588/mcp"
```

### Cursor — `.cursor/mcp.json`
```json
{ "mcpServers": { "chayuan-wps": { "url": "http://127.0.0.1:62588/mcp" } } }
```

### Hermes / OpenClaw
Создайте MCP-службу типа **HTTP / Streamable HTTP**, указывающую на `http://127.0.0.1:62588/mcp` (без токена / команды / stdio).

### Claude Desktop / другие клиенты с JSON-конфигом
```json
{ "mcpServers": { "chayuan-wps": { "url": "http://127.0.0.1:62588/mcp" } } }
```

### Проверка через MCP Inspector
```bash
npx @modelcontextprotocol/inspector   # выберите Streamable HTTP, вставьте URL, Connect
```

> **Устранение неполадок:** если клиент не может подключиться, убедитесь, что WPS открыт и надстройка Chayuan загружена (`GET /healthz` возвращает `online`). Сервер слушает `127.0.0.1:62588`; для удалённых машин потребуется локальный прокси или пользовательский `CHAYUAN_MCP_PORT`. Полное руководство: [docs/mcp-connection.md](docs/mcp-connection.md).

## 4. Обзор продукта

Надстройка для **WPS Writer** (**Vue 3 + Vite**): чат ИИ, суммаризация, анализ текста, перевод, мультимодальность, безопасность и рассекречивание, пакетная обработка документа/таблиц/рисунков, формы, шаблоны и правила, список задач и оркестрация — с записью в документ (**вставка / замена / комментарий / связанный комментарий / добавление в конец**).

**Приоритет офлайн / интранет:** **Ollama** и **OpenAI-совместимые** шлюзы (LM Studio, Xinference, OneAPI, …).
