# wps-skill-chayuan —— WPS 模板编制 + 文档审查校对技能

本技能驱动本机 MCP 服务 `chayuan-wps-mcp`，两大能力：
1. **模板编制**：按用户模板（pptx/docx/xlsx）+ 素材生成新文档；
2. **审查校对**：对 **WPS 中当前活动文档**做审查。模型可能在云或内网 Ollama，批注一定挂在 WPS 稿子上。

## 何时用

- **模板编制**：用户说「按/根据模板（附件1）生成 PPT/文档/表格」「分析附件2 的数据生成年度总结」并提供模板文件路径与素材时。
- **审查校对**：用户说「校对/审查/核稿/检查错别字/术语统一/查序号/结论风险/保密检查」且 WPS 里已打开一份文档时。

## 前置（每次开工先确认）

1. **MCP 在线**：`curl -fsS http://127.0.0.1:62588/healthz` 应返回 `{"ok":true,...}`。不在线就跑 `bash scripts/ensure-mcp.sh`（本技能目录下），仍不行提示用户重开 WPS / 重装。
2. **Agent 在线**：healthz 里 `agent.online` / `agentCount>0`。模板编制按模板类型需要对应宿主（docx→文字 / xlsx→表格 / pptx→演示），目标宿主离线时 template_generate 会自动拉起 WPS，无需人工干预。
3. **模型已配**：若 MCP 报模型相关错误，提示用户去察元设置里配对话模型（云端或 Ollama 兼容端点）。模型配置不归本技能管。

## 模板编制（template_generate）

**工具**：`template_generate`
**入参**：`{"templatePath":"模板绝对路径(pptx/docx/xlsx)","requirement":"生成需求","referenceContext":"素材文本","qcRounds":3(可选,0-4),"pageTarget":页数(PPT可选)}`

行为（调用方无需关心内部）：
- **宿主路由**：按模板扩展名自动派发到 演示/文字/表格 宿主；目标宿主离线自动拉起 WPS 并等待就绪（最长约 45s）。
- **生成流程**：形状级角色剖析（标题/副标题/正文/装饰+字号+坐标）→ 确定性底稿+LLM 计划双轨 → 逐形状填充 → 多轮核对 → 落盘并**自动打开新文档**。
- **多轮核对（打开前）**：占位残留/换行溢出/字体一致性机器审计自愈 + 需求符合性/文案/契约项 LLM 审查；报告里会给各维度 ✓✗。
- **素材要求**：`referenceContext` 传素材**正文文本**（md/txt 内容直接粘入参数）。用户只给文件路径时，先读文件内容再传。

## 文件解析（file_parse）

**工具**：`file_parse`——把本地文件解析成「模型可直接阅读的文本」，素材读取的统一入口（含 template_generate 的素材准备）。
**入参**：`{"paths":["D:\\报告.docx","附件2"],"mode":"auto","budgetTokens":6000}`

- **多路径**：一次 1-8 个；绝对路径，或**附件别名**（用户 30 分钟内在察元面板上传过的附件，说「附件1/刚才那个文件」即可）。
- **格式**：txt/md/csv/json/yaml/html/eml/zip/svg + docx/xlsx/xls/pdf/pptx；旧版 doc/ppt/et 自动经对应 WPS 宿主转新格式再解析（`convertLegacy:false` 可关）；图片音视频不走这里（面板附件自动走识别/转写）。
- **token 纪律（重点）**：返回体带 `tokenEstimate/consumedTokens/budgetTokens`。短文件预算内全文直出；超预算 auto 档给「结构目录(带字符偏移)+头尾采样」并建议 chunk；长文档用 `mode:"chunk"` 翻页（cursor 只前进、读够即停），或按 outline 偏移 `rangeStart/rangeEnd` 直取目标段。`budgetTokens` 按所用模型的上下文给（128k 模型可给 10 万）。
- **示例开场白**：
```
调用 file_parse：paths 用 D:\work\素材.md 与 附件1，budgetTokens 8000；若超预算改 mode=chunk 逐块读。
```

**开场白示例**：
```
调用 template_generate：templatePath 用 /path/to/模板.pptx，requirement 为「生成年度总结PPT」，referenceContext 用附件/文件中的素材正文。
```

**注意**：
- 模板文件不会被修改；产物为新文件并自动打开。
- 生成耗时约 30s~3min（含多轮核对），工具会阻塞到完成；不要中途重复调用。
- 用户说「附件1/上次模板」但没给路径时，先索要路径——MCP 侧不记得上次输入（察元面板内有 30 分钟记忆，但本技能面向裸 MCP 调用方）。

## 审查校对

### 铁律：预览 → 确认 → 写回

**绝不一次性改正文。** 每一次审查分三步：

1. **只读冒烟（首次必做）**：让 MCP 读取当前文档标题和前两段，不写批注、不改正文。确认「活动文档是对的稿子」、工具能定位原文。
2. **预览问题清单（dryRun）**：要求 MCP 输出问题清单（错字/序号/术语/风险…），每条带原文片段 `quote`、类型、建议、理由。**把清单给用户看，不要直接写。**
3. **人工确认后写回**：用户点头，才让 MCP 按批注（`comment`，默认，原文不动）或显式要求的动作写回。替换类动作会让模型改正文，仅在用户明确要求且稿子已备份/开修订模式时用。

### 常用开场白（可复制）

```
通过 chayuan-wps-mcp 读取当前文档标题和前两段，只读，不要写批注，不要改正文。
```
```
审查当前文档的错别字、段落序号、术语一致性，输出 JSON 问题清单（quote/type/suggestion/reason），先预览给我，不要写批注。
```
```
我已确认上面的问题清单，按批注方式（原文不动）写回文档。
```

### 表格与长文

- **表格里的错字**批注可能挂整格——让 `quote` 带上下文，定位更准。
- **长文**走分块审查（meta + chunks），不要一次读完全文；逐块预览→确认。
- **多文档**交叉校对时，先确认活动文档是哪份，避免串稿。

## 边界

- 保密检查、AI 痕迹检查仅辅助参考，**不构成定密或司法结论**；涉密定稿以人工和单位制度为准。
- 模型会读错数字、误判术语——预览阶段是人在兜底，别跳过。
- 涉密稿提示用户用离线模型，正文不出域。

## 自助

- 不在线：`bash scripts/ensure-mcp.sh`
- 端点：`http://127.0.0.1:62588/mcp`（仅 127.0.0.1，无 Token）
- 重装/修复：仓库根 `bash scripts/install-wps-skill-chayuan.sh`（详见 `plans/wps-skill-chayuan-design.md`）
