# wps-skill-chayuan —— WPS 文档审查校对技能

本技能驱动本机 MCP 服务 `chayuan-wps-mcp`，对 **WPS 中当前活动文档**做审查校对。模型可能在云或内网 Ollama，但批注一定挂在 WPS 稿子上。

## 何时用

用户说「校对/审查/核稿/检查错别字/术语统一/查序号/结论风险/保密检查」且 WPS 里已打开一份文档时。

## 前置（每次开工先确认）

1. **MCP 在线**：`curl -fsS http://127.0.0.1:62588/healthz` 应返回 `{"ok":true,...}`。不在线就跑 `bash scripts/ensure-mcp.sh`（本技能目录下），仍不行提示用户重开 WPS / 重装。
2. **Agent 在线**：healthz 里 `agent.online` / `agentCount>0`。若 `WPS_AGENT_OFFLINE`，提示用户打开 WPS 文字并确认察元加载项可见。
3. **模型已配**：若 MCP 报模型相关错误，提示用户去察元设置里配对话模型（云端或 Ollama 兼容端点）。模型配置不归本技能管。

## 铁律：预览 → 确认 → 写回

**绝不一次性改正文。** 每一次审查分三步：

1. **只读冒烟（首次必做）**：让 MCP 读取当前文档标题和前两段，不写批注、不改正文。确认「活动文档是对的稿子」、工具能定位原文。
2. **预览问题清单（dryRun）**：要求 MCP 输出问题清单（错字/序号/术语/风险…），每条带原文片段 `quote`、类型、建议、理由。**把清单给用户看，不要直接写。**
3. **人工确认后写回**：用户点头，才让 MCP 按批注（`comment`，默认，原文不动）或显式要求的动作写回。替换类动作会让模型改正文，仅在用户明确要求且稿子已备份/开修订模式时用。

## 常用开场白（可复制）

```
通过 chayuan-wps-mcp 读取当前文档标题和前两段，只读，不要写批注，不要改正文。
```
```
审查当前文档的错别字、段落序号、术语一致性，输出 JSON 问题清单（quote/type/suggestion/reason），先预览给我，不要写批注。
```
```
我已确认上面的问题清单，按批注方式（原文不动）写回文档。
```

## 表格与长文

- **表格里的错字**批注可能挂整格——让 `quote` 带上下文，定位更准。
- **长文**走分块审查（meta + chunks），不要一次读完全文；逐块预览→确认。
- **多文档**交叉校对时，先确认活动文档是哪份，避免串稿。

## 边界

- 保密检查、AI 痕迹检查仅辅助参考，**不构成定密或司法结论**；涉密定稿以人工和单位制度为准。
- 模型会读错数字、误判术语——预览阶段是人在兜底，别跳过。
- 涉密稿提示用户用离线模型，正文不出域。

## 自助

- 不在线：`bash scripts/ensure-mcp.sh`
- 端点：`http://127.0.0.1:62588/mcp`（仅 127.0.0.1，无 Token）
- 重装/修复：仓库根 `bash scripts/install-wps-skill-chayuan.sh`（详见 `plans/wps-skill-chayuan-design.md`）
