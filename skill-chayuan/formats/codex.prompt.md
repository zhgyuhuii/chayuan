# wps-skill-chayuan —— WPS 文档审查校对

通过本机 MCP 服务 `chayuan-wps-mcp`（`http://127.0.0.1:62588/mcp`，仅 127.0.0.1、无 Token），对 **WPS 中当前活动文档**做审查校对：错别字、段落序号、术语统一、结论与风险、保密检查等。模型可能在云或内网 Ollama，但批注一定挂在 WPS 稿子上。

## 适用
用户说「校对 / 审查 / 核稿 / 检查错别字 / 术语统一 / 查序号 / 结论风险 / 保密检查」且 WPS 里已打开文档时。

## 开工前置（每次先确认）
1. **MCP 在线**：`curl -fsS http://127.0.0.1:62588/healthz` 返回 ok。不在线跑 `bash scripts/ensure-mcp.sh`，仍不行提示重开 WPS / 重装。
2. **Agent 在线**：healthz 里 `agent.online` / `agentCount>0`；离线则提示打开 WPS 文字、确认察元加载项可见。
3. **模型已配**：模型错误提示用户去察元设置配对话模型；模型配置不归本技能管。

## 铁律：预览 → 确认 → 写回
**绝不一次性改正文。** 每次审查三步：
1. **只读冒烟（首次必做）**：让 MCP 读当前文档标题和前两段，不写批注、不改正文，确认活动文档正确、工具能定位原文。
2. **预览问题清单（dryRun）**：MCP 输出问题清单（错字 / 序号 / 术语 / 风险…），每条带 `quote` / 类型 / 建议 / 理由。**给用户看，不要直接写。**
3. **人工确认后写回**：用户点头才让 MCP 按批注（默认，原文不动）或显式动作写回。替换类改正文仅在用户明确要求且已备份 / 开修订模式时用。

## 表格与长文
- 表格错字批注让 `quote` 带上下文。
- 长文走分块（meta + chunks），逐块预览 → 确认。
- 多文档交叉校对先确认活动文档是哪份。

## 边界
- 保密检查 / AI 痕迹检查仅辅助参考，**不构成定密或司法结论**；涉密以人工和单位制度为准。
- 模型会读错数字、误判术语——预览阶段是人在兜底，别跳过。
- 涉密稿用离线模型，正文不出域。
