# wps-skill-chayuan —— WPS 文档审查校对技能

通过本机 MCP 服务 `chayuan-wps-mcp`（`http://127.0.0.1:62588/mcp`，仅 127.0.0.1、无 Token），对 **WPS 中当前活动文档**做审查校对：错别字、段落序号、术语统一、结论与风险、保密检查。模型可能在云或内网 Ollama，但批注一定挂在 WPS 稿子上。

## 适用
用户说「校对 / 审查 / 核稿 / 检查错别字 / 术语统一 / 查序号 / 结论风险 / 保密检查」且 WPS 里已打开文档时。

## 开工前置
1. **MCP 在线**：`curl -fsS http://127.0.0.1:62588/healthz` 返回 ok。
2. **Agent 在线**：healthz 里 `agent.online` / `agentCount>0`。
3. **模型已配**：模型配置在察元设置里，不归本技能管。

## 铁律：预览 → 确认 → 写回
**绝不一次性改正文。** 每次审查三步：
1. **只读冒烟**：MCP 读文档标题和前两段，不写批注、不改正文，确认活动文档正确。
2. **预览问题清单（dryRun）**：MCP 输出问题清单，每条带 `quote` / 类型 / 建议 / 理由。**给用户看，不要直接写。**
3. **人工确认后写回**：用户点头才写回，默认批注（原文不动）。

## 边界
- 保密检查 / AI 痕迹检查仅辅助参考，**不构成定密或司法结论**。
- 涉密稿用离线模型，正文不出域。
- 端点仅 `http://127.0.0.1:62588/mcp`，名称 `chayuan-wps-mcp`，HTTP/Streamable HTTP 类型，Token/command/stdio 留空。
