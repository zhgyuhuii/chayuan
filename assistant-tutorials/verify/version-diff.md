# 两版合同到底改了哪几处实质,「两版差异核对」帮你只看要紧的

对方发来合同的新版本,说"小改了几处"。你不放心,得一字一句比。可纯排版、标点的变化把你淹没,真正动了金额、改了责任的那几处反而难找。「两版差异核对」是察元AI文档助手里帮你只盯实质改动的助手。

**它怎么用**
把两版文本贴进同一个文档,用"【版本A】""【版本B】"分隔标好,点运行。它只报实质性的增删改——条款、数字、主体、义务、金额、期限的变化,忽略空格、换行、标点这些纯格式差异。每处差异把 A、B 两侧的原文都引出来,标明变化类型,并重点标出"对责任/金额/期限/权利有实质影响"的改动。

**谁用得上**
反复改合同、改协议、改方案的人;核对方"小改"到底改了什么的商务、法务。

**找到它**
WPS 装"察元AI文档助手",在"文档核对"分类或搜"差异""版本"找到它。结果默认追加一份差异清单到文末。

**一个前提**
它比的是你贴进去用 A/B 标好的两段文本,所以记得把两版都放进来、分隔标清楚。

**结合知识库**
要比的是"这版和我方标准范本差在哪",把范本放进知识库,用"标准模板符合性"助手对照更直接。

**改它**
默认盯实质改动。你想连格式改动也看,可在提示词里放宽。

**模型**
逐字比对要细,建议中档以上对话模型。

**和超级智能体配合**
两版手动比在 WPS 里做;要在多轮往来里追踪一份合同每一版改了什么、形成修订轨迹,交给桌面端察元AI超级智能体。

对方说"就改了几个小地方"时,让它替你确认到底改了哪几处、要不要紧。
