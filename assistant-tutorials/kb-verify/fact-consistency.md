# 文档里的说法和公司资料对不对得上,「知识库事实核查」帮你逐条比

单篇核对只能查文件"内部"自不自洽,查不了"和事实对不对"。比如一份对外稿写着某产品参数、某政策口径,到底和公司权威资料一致吗?这得有个比对的基准。「知识库事实核查」是察元AI文档助手里的助手,它会去你绑定的知识库里检索,把文档的事实性陈述和库里的内容逐条比。

**先决条件:绑定知识库**
用这个助手前,先在对话侧栏绑定相关知识库(产品资料、政策文件、标准口径都行)。它运行时会拿文档去库里检索命中片段,再做比对。没绑库,它会直接告诉你"未绑定知识库",不会硬编一个结论——这是它的底线。

**它产出什么**
逐条判定"一致 / 冲突 / 知识库未覆盖"。冲突的,把文档原文和知识库依据两边的原句都引出来;库里没有的,标"未覆盖,无法核实",提醒你别当成已证实。

**谁用得上**
对外发稿前要核口径的市场、品宣;答复、解读要和政策对齐的人;任何"说法必须和权威资料一致"的场景。

**用起来**
WPS 装"察元AI文档助手",绑好知识库,打开文档,在"知识库对比"分类找到它,点运行。结果以批注形式贴在有问题的陈述旁。

**它和单篇核对的区别**
单篇核对查"前后一不一致",它查"和外部基准一不一致"——多了一个权威参照,能发现单文档发现不了的事实错误。

**模型**
要理解语义再比对,建议中高档对话模型。

**和超级智能体配合**
WPS 里核单篇;要把一批稿件都拿去和知识库核、或接更大的资料库做深检索,桌面端察元AI超级智能体更扛得住量。两端共用同一套知识库和授权。

发出去之前,让它拿公司的"标准答案"先对一遍。
