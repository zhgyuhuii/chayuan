# 文里引的内容在不在知识库里有据,「引文知识库核验」帮你溯源

文档里引了一段政策、一个数据、一句出处,说得有鼻子有眼。但这些真有出处吗,还是顺手编的?光靠模型记忆核不可靠。「引文知识库核验」是察元AI文档助手里的助手,拿你绑定的权威资料库,核文档里的引用能不能在库里找到对应来源。

**先绑权威库**
在对话侧栏绑定权威资料库(法规库、标准库、官方文件、公司档案等)。助手运行时拿文档里的引用去库里检索对应来源。

**它产出什么**
逐条核验:能对应的,给出知识库里的依据原句;库里找不到的,标"知识库无此出处,存疑,建议人工核实"——它不替你判这条引用是真是假,只告诉你"在不在我们的资料里有据"。

**谁用得上**
写政策解读、研究报告、法律文书、论文的人;以及审稿要核引用的编辑。

**用起来**
WPS 装"察元AI文档助手",绑好库,打开文档,在"知识库对比"分类找到它,点运行。引用处贴批注,标核验结果。

**它和单篇"法条引用核查"的关系**
单篇那个靠常识看引用规不规范,核不了真伪;这个有权威库当依据,能真去比对出处在不在——要核引用的准确性,这条路更靠谱。

**模型**
要溯源比对,建议中档以上对话模型。

**和超级智能体配合**
单篇核引用在 WPS 里做;要接大型法规/文献库做大规模引用核验,交给桌面端察元AI超级智能体。

引用是文章的信用背书,发出前让它溯一遍源,别让一个查无出处的引用砸了招牌。
