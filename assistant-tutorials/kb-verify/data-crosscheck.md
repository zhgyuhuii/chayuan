# 文档里的数字和台账数对不对得上,「数据知识库对照」帮你核

报告里引了一堆数字——销售额、产能、人数、占比。这些数和公司台账、官方口径对得上吗?光看文档内部加总没用,得有个权威数据源去比。「数据知识库对照」是察元AI文档助手里的助手,拿你绑定的数据知识库,把文档里的关键数字逐个核。

**先绑数据库**
在对话侧栏绑定含基准数据的知识库(台账、统计口径表、官方发布数据等)。助手运行时拿文档去检索对应数据,再比。

**它产出什么**
逐项判"一致 / 不一致 / 口径不同 / 知识库未覆盖"。不一致的,文档和知识库两边数字都引出来;口径不同的(同比vs环比、含税vs不含税),它会点明差在口径而不是数错。

**谁用得上**
做经营分析、对外披露、汇报的人,数字必须和台账对得上;以及核数据材料的财务、运营。

**用起来**
WPS 装"察元AI文档助手",绑好数据库,打开文档,在"知识库对比"分类找到它,点运行。对不上的数字处贴批注,带核算和依据。

**它和单篇"数字金额核对"的区别**
单篇那个查"文档内部加总自不自洽";这个查"和外部基准数对不对得上"——多了权威参照,能抓出"算得对但抄错来源"的错。

**模型**
数字比对要稳,建议中档以上对话模型。

**和超级智能体配合**
单份核数在 WPS 里做;要把一批报表都和台账核一遍、出差异表,交给桌面端察元AI超级智能体。

对外报数前,让它拿台账先对一遍,别让一个抄错的数字闯了祸。
