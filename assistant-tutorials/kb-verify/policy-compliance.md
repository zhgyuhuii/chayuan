# 这份文件合不合公司制度,「制度合规对照」拿你的制度库逐条比

"合不合规"这种事,通用助手答不了——它不知道你们公司的制度长什么样。你得先把制度交给它。「制度合规对照」是察元AI文档助手里的助手,它以你绑定的制度/规范知识库为基准,检查当前文档符不符合。

**先把制度放进知识库**
在对话侧栏绑定公司制度库(员工手册、采购制度、财务规定、安全规范等)。助手运行时会拿文档去库里检索相关条款,再判文档里的做法/表述是否符合。没绑库就提示你先绑,不瞎判。

**它产出什么**
逐项判"符合 / 违反 / 知识库未规定"。违反的,把文档原文和对应制度条款两边都引出来,给整改建议;库里没规定的标出来,不替你强行裁定。

**谁用得上**
合规、内审、风控;以及写制度执行类文件、要自查合不合规的各部门。

**用起来**
WPS 装"察元AI文档助手",绑好制度库,打开文件,在"知识库对比"分类找到它,点运行。违反项贴批注,带制度依据。

**为什么必须靠知识库**
合规的判据是"你们的制度",不是通用常识。把制度喂进去,它才查得准、说得出依据,而不是泛泛而谈。

**改它**
默认通用合规视角。你想重点查某一类制度,在提示词里强调,并在侧栏只绑相关那本制度库。

**模型**
要条款对照,建议中高档对话模型。

**和超级智能体配合**
单份自查在 WPS 里做;要按整套制度批量体检大量文件、出合规报告,交给桌面端察元AI超级智能体。

把制度交给它当尺子,比你凭记忆判合规靠谱。
