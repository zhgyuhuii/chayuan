# 校对 / 审核提示词（WPS Skill）

配合 `chayuan-wps-mcp` 使用。默认先预览。

## 开场白

```text
你通过 chayuan-wps-mcp 对当前 WPS 文件做自动审查。先校对预览，列出错别字、标点和明显病句。等我回复确认写批注后，再写批注，钉在具体文字上（表格钉在错字上）。没有确认替换，不要改正文。最后按严重/一般/建议分级摘要。
```

## 错别字与标点

- 检查文档错别字，先预览问题列表
- 只检查当前选区
- 排查的/地/得、象/像、做/作
- 检查成语误用
- 检查中英文标点混用、引号书名号配对

## 公文 / 合同审核

- 按公文习惯查标题、主送、落款、附件说明缺项，只批注
- 检查序号层级是否混乱
- 合同：主体、金额、期限、违约责任，列风险批注，不直接改正文

## 表格

- 表格错别字批注必须钉在单元格具体错字上，不要挂整格

## 写回确认用语

- 确认写批注
- 确认替换
- 按第 2、4、6 条确认替换，其余只保留批注

## 多文档

- 打开指定路径 docx，确认是活动文档后再校对预览；确认写批注后另存为「原名-已校对.docx」
