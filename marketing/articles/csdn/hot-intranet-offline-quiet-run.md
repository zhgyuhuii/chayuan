# 察元AI文档助手离线跑：不联外网的电脑也能 AI 校对

很多单位的现实是，写材料的电脑不许联外网，一个口子都不开。可活还是那些活，报告照写，错别字照查。一边看外面的人用智能体提效，一边继续人肉通读。

其实断网机器上这套是能跑的，前提是把模型搬到网内。用察元AI文档助手加 Ollama，完整链路如下。

下载安装。官网 aidooo.com 下载离线安装包，拷进内网机器安装，装完重启 WPS。加载项连的文档服务跑在本机，端口 62588，不需要外网。

配置。两头。模型这头，内网找一台有显卡的机器用 Ollama 部署开源模型，科室其他电脑把模型接口指过去，一台卡全科室共用。智能体这头，终端执行 claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp。配置里外部模型供应商一栏留空，想发外网都没地方发。

验证。浏览器打开 http://127.0.0.1:62588/healthz，返回 ok 即通。安装脚本的四级自检也会自动跑这一步。

测试。说一句：读当前文档前两段。能正常返回内容，说明本机服务和内网模型都通了。

使用。WPS 打开文档，对智能体说校对指令，它读原文、列清单、挂批注，确认在人。校对任务对模型要求没想象中高，关键是加载项的技能模板把流程约束住了，系统提示词写死、温度调低、输出固定格式，换个便宜点的开源模型，结果照样稳。

提示词给三条。
一、校对当前文档的错别字和段落序号，结果挂批注，先预览清单。
二、把全文术语的不同写法列出来，标出位置，等我确认再统一。
三、把当前文档与上一份打开的文档交叉核对数据，只报不同。

内网不是落后，是把边界画清楚。边界里面，该有的效率一样能有。
