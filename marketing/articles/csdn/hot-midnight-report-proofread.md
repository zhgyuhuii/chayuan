# 察元AI文档助手实测：晚上十点接活，四十分钟交出十五页报告校对

周三晚上十点，领导发来一份十五页的年度情况报告，说明天上午要用，让我把错别字和前后不一致的地方过一遍。搁以前这是通宵的活，逐字读、拿笔记，读到最后心里也没底。

这次我全程用察元AI文档助手跑的，从装到交四十分钟，过程写下来。

下载安装。官网 aidooo.com 下载 Windows 安装器，双击装完重启 WPS，功能区就有入口。也可以用官网那行 PowerShell 一行命令，自动装加载项、配自启、跑检查。

配置。终端里执行 claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp，一回车智能体就接上了，本机地址不要 token。

验证。浏览器打开 http://127.0.0.1:62588/healthz，返回 ok 就是活的。

测试。先来一句小的：读一下当前文档的标题和总段落数。答对了，链路才是通的，再上正稿。

使用。WPS 打开报告，我对智能体说：对当前文档整体校对，错别字、序号跳号、术语混用都查，先给我清单，确认后挂批注，不要动正文。十几页它分块读，几分钟后交回清单，每条带原文、建议和理由。有一条年份写法被误判，我勾掉，其余确认，批注一条条挂上去。第二天起草科室点着批注改，全程留痕。

常用的几句提示词放这。
一、对当前文档做错别字校对，只列问题清单，每条含原文、建议、理由，先预览。
二、核对全文段落序号连续性，跳号和重号单独列出。
三、把文中同一概念的不同写法列出来，标出每处位置，先不动正文。

最后提醒，数字对不对模型只能提线索，交稿前数据还得人工过一遍。但那晚我确实睡了。
