# 每周汇报别再手工套模板了：把公司模板交给 AI，让它按形状对位出整套文档

> 垂直场景文，写给每周都在"套模板"的行政、办公室与汇报岗。约 2500 字。

## 一、模板的悖论

几乎每个单位都有一套"母版"：汇报 PPT 有固定的封面、目录、章节页、结尾页；公文有红头和版式；周报表格有固定栏目。模板的意义是统一口径，但**填模板**这件事本身极烦：

- 每页的文本框位置、字号、字体都不一样，新内容粘进去经常撑爆版式，或者空一大半；
- 封面标题、章节标题、目录条目要对位，手滑就错位；
- 最贵的不是时间，是"模板被改坏"——某页不小心动了母版，整套文件的口径就花了。

察元 AI 文档助手（v6.1 起的主线能力）把这件事做成了对话：**给一个模板文件 + 一句话要求，产出整套文档**。它是运行在 WPS 三端的 Apache-2.0 开源加载项（[GitHub](https://github.com/zhgyuhuii/chayuan)），模板编制直接跑在 WPS 文字 / 表格 / 演示内部，不换工具。

## 二、闭环长什么样

### 1. 模板四件套先就位

功能区里有配套的模板工具：**导出模板 / 导入模板 / 从模板新建 / 下载模板**，外加规则制作 / 规则导入 / 导出规则。团队可以把母版和填制规则一起共享——口径对齐靠文件流转，而不是靠口头交代。

### 2. 对话里给模板 + 一句话

首页对话里拖入模板文件（.pptx / .docx / .xlsx），说"按这个模板出一份 10 页的三季度产品介绍，素材在附件里"。系统按模板类型**自动路由到对应宿主**——pptx 去演示、docx 去文字、xlsx 去表格；目标宿主没开就自动拉起并等待就绪，生成完对话自动跟到新文档窗格。

### 3. 形状级剖析：它"看得懂"你的模板

这是整套能力的技术核心。它不是把模板当背景图，而是**逐页剖析每个形状的角色与属性**——这是标题、这是副标题、这是正文、这是装饰，同时记录字号、字体、坐标。填充规则按角色走：

- 封面页吃文档主标题，内容页吃章节标题；
- 目录条目按序号对位，不串行；
- 隐形水印识别为装饰，保持原样不覆盖；
- 新内容按原形状的容量截断，不撑爆版式；
- 新文字写入主文本 run，**继承模板的中文字体**——不会出现"内容是对的、字体花了"的尴尬。

### 4. 打开前多轮核对，逐维 ✓ / ✗

生成完不直接塞给你：先过机器审计（占位符残留 / 文本溢出 / 字体一致性三查）+ 自愈闭环修掉问题，再过 AI 多维审查（需求符合性、文案质量、逐项核查）。默认 **3 轮、上限 4 轮**，每一轮每一维都给你 ✓ / ✗ 的明细——你能看到它自检的过程，而不是收到一个黑盒产物。

### 5. 字节级交付

产物是**模板的字节级拷贝再填内容**：母版、版式、背景、字体原样保留。可以原地交付，也可以自动打开新文档；下次生成还会自动记住上次的输入——周报这种每周重复的活，第二周起只需要换素材。

## 三、给智能体玩家的入口

这套能力同样暴露在 MCP 上：`template_generate` 工具——按模板 pptx / docx / xlsx + 素材，后台生成整套新文档并自动打开（同样走多轮核对）。也就是说，Claude Code / Cursor 这类智能体可以把它编进自动化流水线："每周五用公司模板自动生成本周数据周报"是一个可落地的工单，不是幻想。

## 四、落地三步

1. **把母版整理干净**：占位内容完整、形状角色清晰（标题就用标题占位符，别拿文本框手写封面）；
2. **对话给模板 + 一句话**（或经「察元AI编审」的模板管理入口走正式流程）；
3. **过一遍多轮核对明细**，人工审校后再对外使用。

## 五、说清边界

- **效果依赖模板结构**：形状角色清晰的规范模板对位效果好；创意型版式、自由拼贴式设计，机器剖析的把握会下降——模板越规范，产出越稳；
- **隐形水印会被保留**：这是特性也是约束——模板里藏了什么"隐藏元素"，交付物里就有什么，外发前自己心里要有数；
- **产物必须人工审校**：多轮核对能拦住占位残留、溢出、字体不一致这类硬伤，但内容口径、数字、提法，对外前仍要人拍板。

一句话收束：模板编制不解决"设计"问题，解决的是"填制"问题——设计交给设计师，填制交给流水线。
