# 文档审计助手：书签级逐项复核怎么跑

场景先摆出来：合同模板年中升了一版，几十份在途合同要按新口径把关键条款逐项再过一遍；再加上季度抽检，法务两个人排了三天没排完。后来这活交给察元的文档审计助手跑书签级逐项复核，一个下午收尾。这篇按操作顺序讲怎么跑，装过的同学可以直接跳到第二步。

## 前置：环境就位

没装过的 Windows 上开 PowerShell 跑官方一行命令（自动处理 GBK/BOM 乱码）：

```powershell
& {[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$w=New-Object Net.WebClient;$w.Encoding=[Text.Encoding]::UTF8;$s=$w.DownloadString('https://gitee.com/cloudshd/chayuan-wps-releases/raw/master/scripts/install-wps-skill-chayuan.ps1');if($s.Length -and $s[0]-eq[char]0xFEFF){$s=$s.Substring(1)};& ([scriptblock]::Create($s)) -Fetch}
```

装完脚本自己做四级体检，浏览器开 http://127.0.0.1:62588/healthz，看到 online 就绪。macOS 和 Linux 也有对应的安装脚本，仓库里的说明写得很清楚。如果菜单在但没反应，先看健康检查通不通；提示 WPS_AGENT_OFFLINE 说明 WPS 或加载项没连上服务，重启 WPS 一般就恢复。

## 第一步：定审计项

审计跑得顺不顺，取决于"审什么"定得清不清楚。我们的做法是先在部门内把关键条款清单固化成规则文件（察元 AI 编审 → 模板与规则，aidooo 扩展名，支持导入导出）：主体条款、价款与支付、履行期限、验收标准、违约责任、争议解决，一项一行。清单是法务定的，机器只负责逐项过——这一步别省，清单越具体，审计结果越可用。

## 第二步：跑文档审计

WPS 打开合同，进察元 AI 编审 → 文档审计。审计是书签级的：按书签逐项复核，每一项给出对应的审计结果，这一条过了没过、缺没缺，一目了然，不用人再回到正文里逐段找。几十份合同批量过下来，真正需要人看的只剩审计标出来的那几项。第一次跑建议拿一份已经人工审过的合同做对照，感受一下它的覆盖面和判断尺度，再上真实批次。长合同不用担心读不全：先 document_meta 看字数、段数和是否建议分块，超长就 document_chunks 分页读，四十页的框架合同连附件带补充协议也能整份过完，不会审到后半本开始"跳页"。

## 第三步：疑点转批注

需要留痕的疑点转成批注。走 MCP 的团队可以这样下指令（Claude Code 先注册：claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp）：

> 按关键条款清单逐项审计这份合同，缺项和表述异常的条款用批注标出原文位置；写批注前先列出将写入的批注清单给我确认。

对应工具层的设计：document_add_comment 必须传 confirmed:true 才落盘，所以智能体会先列清单再等你点头——这个节奏正好是法务需要的。批量写回用 document_apply_ops，一次上限 200 个操作，够一份合同的批注量了。

## 第四步：用印前终检

批注处理完、清零之前，跑一遍终检提示词兜底：

> 帮我做发布前终检：错别字、标点、数字前后一致性、表格与正文是否一致；全部用批注输出；最后给我一份问题分级摘要（严重/一般/建议）。

审计管"条款齐不齐"，终检管"文本干不干净"，两道互不替代，都过完再进用印流程。

## 第五步：结果留档

复核完的文档用 document_save 另存一份带审计痕迹的版本归档（工具支持另存为），审计摘要贴进台账。谁的合同、哪一版、按什么清单审的、结论如何，全程可回溯——将来发生争议，这套留痕就是流程合规的证据链。

## 边界说清楚

文档审计助手报的是"有没有、对不对得上清单"，不是"条款合不合法、该不该签"。清单本身要法务维护，审计结果要法务签收，AI 在这条流水线里是复核工具，不是审查主体，更不替代律师意见。机器把几十份合同缩成十几条疑点，人把这十几条疑点逐条定性——三天排不完的抽检压缩到一个下午，这就是书签级复核的实际价值：不是审得更省事，是把人力从"翻"挪到"判"。适合这套流程的岗位也很明确：管在途合同的法务、做季度抽检的合规、以及经常按新模板回头复核旧合同的合同管理员。
