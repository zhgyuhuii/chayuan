# 周报自动汇编：提取行动项和结论风险两条线

周五下午四点，八个组的周报陆续落到我收件箱里，我的任务是把它们汇编成一份部门周报交总监。以前这活要吃掉周五整个晚上：通读、摘抄、去重、排格式。这篇按"下载—配置—验证—使用"完整走一遍我现在的流程，工具是察元AI文档助手，WPS 加载项形态开箱即用，同时带一个本机 MCP 服务，Claude Code、Cursor 这类 Agent 可以直连。

## 一、下载安装

Windows 下 PowerShell 一行命令（脚本自动处理 GBK 乱码、多源回退下载和 sha256 校验）：

```powershell
& {[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$w=New-Object Net.WebClient;$w.Encoding=[Text.Encoding]::UTF8;$s=$w.DownloadString('https://gitee.com/cloudshd/chayuan-wps-releases/raw/master/scripts/install-wps-skill-chayuan.ps1');if($s.Length -and $s[0]-eq[char]0xFEFF){$s=$s.Substring(1)};& ([scriptblock]::Create($s)) -Fetch}
```

这一个脚本干三件事：装好 WPS 加载项、把本机 MCP 服务注册成开机自启、给 Claude/Cursor/Codex 投放技能文件。装完重启 WPS 就能看到加载项。

## 二、配置模型

设置里填 OpenAI 兼容端点即可。我们部门内网走 Ollama，LM Studio、Xinference、OneAPI 也都支持，云端供应商可以并行配置。周报这种内部材料，我坚持只走本地模型，内容一个字不出网。

## 三、验证服务

浏览器访问健康检查地址，返回 online 说明本机服务活着：

```text
GET http://127.0.0.1:62588/healthz
```

服务只监听 127.0.0.1，本机即信任边界，不需要配 Token，这点对内网环境很友好。

## 四、汇编的两条线

八份周报合成一份 WPS 文档后，我固定跑两条线。

**行动项线。** 选中全文，用内置的"提取行动项"助手，或在自定义助手里写死提示词：

```
从本周各部门周报中提取行动项，每条注明责任事项、责任组、截止时间，按组归类输出为清单，追加到文末
```

写回动作选"追加到文末"，结果直接落在周报末尾，我再用表格工具整成一览表，谁欠什么事一眼看全。

**结论与风险线。** "提取结论与风险"助手负责把各组写的成果和隐患分拣出来。汇编周报最难的就是这两块散在八份文档里——人工抄漏一条风险，月底就变成事故复盘会上的名字。

两条线跑完，我必补一个人工动作：通读清单，合并重复项、标注口径不一致的地方。这步不能省，AI 分拣按文本相似度走，跨组同一件事的两种写法它未必归到一起。

顺带说两个提效细节。其一，这两个提示词不用每次现敲：加载项支持自定义智能助手，把系统提示、输入来源（我设成"全文"）、输出格式、写回动作（追加到文末）一次配好，还能挂到 Ribbon 主菜单或右键菜单上，每周点两下就完事。其二，行动项清单要成表的时候，先让 AI 输出带表头的结构化文本，再用表格工具插行列、调列宽；表格操作是按"在哪插"这种口语描述定位的，说"在表头下面插一行"它自己找锚点。

另外别被"八份文档"吓到。汇编后的部门周报其实不长，但如果你管的是十几个组的月度汇总，动辄几万字，它的工具链会先读文档元信息判断是否分块，长文自动按块处理，行动项一条不落。我试过十四个组的月报合并，提取质量没有肉眼可见的衰减。

## 五、进阶：让 Agent 接管整条链路

用 Claude Code 的话，一条命令挂上 MCP：

```bash
claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp
```

之后可以直接下指令"打开周报目录里的八份文档，提取行动项汇总成表插到新文档"，四十六个文档工具会自己组合调用，长文自动分块读，表格自动定位。要改动正文时它默认只给预览，你确认了才真正写盘——周报这种要抄送领导的文档，这个确认环节比省事更重要。

## 写给同岗的一句话

这套流程适合谁：每周汇总下属材料的管理岗、项目群周报接口人、兼任各部门信息收口的行政。关于 AI 就业焦虑也说一句实话：汇编岗没有被取代，是被升级了。以前我的周五晚上花在复制粘贴上，现在花在判断哪条风险该升级上报上。工具接走了机械部分，判断部分反而更值钱——先学会把机械部分交出去的人，焦虑会小很多。流程跑顺之后，周五晚上六点前交周报，成了我们组的新常态。
