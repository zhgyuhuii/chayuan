# 一行 PowerShell 装好 WPS 加载项、MCP 自启和 AI 技能：行政岗十分钟上手察元AI文档助手

做行政的朋友大概都经历过这种晚上：一份几十页的总结材料，领导明早要看，你从晚上九点开始逐字找错别字，找到十一点眼睛发花，第二天还是被挑出一个"的、地"用错。这种活最磨人的地方在于没什么技术含量，但就是费人费眼，还没人觉得你在创造价值。

2026 年这波 AI Agent 办公落地，最先被接走的就是这类重复劳动。我最近在科室里推的工具是 WPS 加载项「察元AI文档助手」：开源项目，Apache-2.0 协议，当前版本 4.1.2。它让 AI 直接进 WPS 文档里干活——读正文、圈错别字、写批注、批量替换、插表格行列、多文档交叉校对。对行政岗来说最实际的一句话是：安装只要一行 PowerShell，十分钟从零到能用。

## 第一步：复制这一行，回车

开始菜单搜 PowerShell 打开，把下面这行原样粘贴进去，回车：

```powershell
& {[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$w=New-Object Net.WebClient;$w.Encoding=[Text.Encoding]::UTF8;$s=$w.DownloadString('https://gitee.com/cloudshd/chayuan-wps-releases/raw/master/scripts/install-wps-skill-chayuan.ps1');if($s.Length -and $s[0]-eq[char]0xFEFF){$s=$s.Substring(1)};& ([scriptblock]::Create($s)) -Fetch}
```

这一行干的事比看起来多：先从 Gitee 拉安装脚本，中间那几行 Encoding 和 BOM 处理，是专门解决老版 PowerShell 5.1 下载脚本时 GBK/BOM 乱码问题的——单位里一批没升级过的电脑全靠这个才能装顺。下载安装包时走 Gitee → aidooo → GitHub 多源回退，每个包带 sha256 校验，不怕弱网下到残包。

## 第二步：看懂脚本的四步闭环

这个脚本不是"下载完请手动配置"那种半成品，它是一条龙跑完四步：

1. 装 WPS 加载项：文件落进 jsaddons 目录并注册 publish.xml，WPS 文字打开即加载；
2. 装 MCP 服务并设开机自启：chayuan-mcp 是单文件二进制，全程不需要你装 Node.js，自动注册进当前用户的自启项；
3. 四级体检：从 jsaddons 文件、healthz 健康检查、initialize 握手到桥接工具，逐层确认链路是通的；
4. 往 Claude Code、Cursor、Codex 这些外部 AI 工具里投放技能文件。

也就是说装加载项、装常驻服务、投 AI 技能三件事一次到位。装完重启 WPS 文字，加载项就挂上了。

## 第三步：一分钟验证服务活着

浏览器地址栏打开 `http://127.0.0.1:62588/healthz`，页面返回 online 就说明本机 MCP 服务在跑。这个服务只监听 127.0.0.1，不对外发包，数据不出本机，这点在单位电脑上用着放心。

## 第四步：第一次实战校对

打开一份待检文档，在加载项的助手列表里选「拼写与语法检查」——这是它内置的二十九个助手之一，不接外部 AI 工具也能直接用，涵盖生成摘要、翻译、术语统一、会议纪要、公文风格改写这些编编改改的场景。

想要更可控的玩法，可以在接好的 AI 工具里直接下指令，比如这句可以直接复制：

```text
帮我检查文档中的错别字，用批注标出原文和建议改法
```

背后 AI 会先走 dryRun 只返回问题清单，你确认之后再通过 `proofread_apply_comments` 把问题逐条写成批注，钉在原文位置上，表格单元格里的错字也能钉到具体位置。这种"先看清单再落笔"的两段式，比一键全文改要踏实得多。

公文场景还有两句常用指令，可以直接复制。一句查体例：

```text
检查标题/条款序号（一、（一）、1.）是否层级混乱，批注指出
```

另一句做数字勾稽：核对数表与正文数字是否一致（合计、百分比）。前者靠 AI 读段落结构找层级错乱，后者会把表格和正文来回对照，这两类恰恰是人眼最容易漏、又最容易被领导当场挑出来的问题。要更稳一点，还可以加一句"先跑一遍校对（dryRun），汇总问题列表，不要先改正文"，把预览和写回拆成两步走。

## 几句实话

- 已装过的老用户想升级，重新跑一遍那行命令就行，覆盖升级，旧配置不动；4.1.2 版本修了 sidecar 启动弹黑窗的问题，现在后台服务隐藏启动，不会再冒出吓人的控制台窗口；4.1.1 之后连安装脚本的临时解压目录都会退出即清理，老版本每次装完残留约 290MB，C 盘紧张的机器建议都刷上来。
- 批量的活也接得住：表格批量导出、按文字删行列、自动行宽，图像批量导出、统一格式，还有清理空白行这类文档整理，都在加载项里点选就能跑，行政月报季报那种十几张表的文档最受益。
- 校对结果是辅助参考，真正定稿、定密还是要人来拍板，AI 的价值是把可疑的地方一次性全捞出来，不替你签字。
- 单位不允许连外部 API 的话，它可以接 Ollama、LM Studio 这类本机模型端点，纯内网也能跑。

十分钟装好，第一份文档就能省下一晚上对灯瞪眼的时间。行政岗用的 AI 工具，我觉得就该做到这个份上：装的时候不折腾人，用的时候真省事。
