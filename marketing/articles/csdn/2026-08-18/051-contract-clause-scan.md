# 合同关键条款缺项扫描：主体、金额、期限、违约责任一个不漏

做合同审查的人都知道，最尴尬的不是发现错别字，而是合同用印之后才发现：违约责任条款整条没了。错字是面子问题，缺项是里子问题。三十多页的采购合同，附件三四个，改到第七版，某次修订里一条被顺手带走了——这种事靠人眼一页页翻，翻到第二十页注意力就撑不住了。

我们部门现在的做法，是把"缺项扫描"这道工序交给察元AI文档助手做预筛：它跑得快、不跳行、每一版口径变化之后都能原样重跑一遍，人只对它标出来的疑点做判断。这篇按教程顺序走一遍完整流程，从安装到出批注。

## 第一步：装好加载项和本机服务

Windows 上开 PowerShell，跑官方一行命令（脚本会自动处理 PS 5.1 的 GBK/BOM 乱码问题）：

```powershell
& {[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$w=New-Object Net.WebClient;$w.Encoding=[Text.Encoding]::UTF8;$s=$w.DownloadString('https://gitee.com/cloudshd/chayuan-wps-releases/raw/master/scripts/install-wps-skill-chayuan.ps1');if($s.Length -and $s[0]-eq[char]0xFEFF){$s=$s.Substring(1)};& ([scriptblock]::Create($s)) -Fetch}
```

脚本一条龙做四件事：装加载项（写进 jsaddons 目录和 publish.xml，WPS 打开即加载）、MCP 服务自启（单文件二进制，注册开机自启，不依赖 Node.js）、四级体检确认链路通、顺手把技能文件投放到 Claude、Cursor、Codex。当前版本 4.1.2，Apache-2.0 开源。装完重启 WPS，就能看到察元的菜单。

## 第二步：验证服务在线

浏览器访问健康检查地址，返回 online 即正常：

```
http://127.0.0.1:62588/healthz
```

服务只监听 127.0.0.1，本机即信任边界——合同文件不出这台电脑，这对法务场景是硬前提。模型侧接 Ollama、LM Studio 这类本地端点，整条链路不出域；个别场景需要更强能力，也可以并行配置云端供应商，看各单位的保密尺度。

## 第三步：跑缺项扫描

最轻的用法不涉及外部智能体：WPS 里打开合同，用内置助手直接跑。察元带 29 个内置助手，"表单智能提取"能把合同关键字段抽成 JSON，"提取结论与风险"先过一遍风险点。缺项扫描我习惯走 Claude Code，把这条提示词发给它：

> 检查这份合同的关键条款是否齐全：合同主体、价款金额、履行期限、验收标准、违约责任、争议解决；缺项或表述明显异常的条款，用批注标出原文位置并说明缺了什么；先给我问题汇总清单，我确认后再写成批注。

这条提示词有三个小心思：一是把检查项列死，防止 AI 自由发挥；二是要求批注钉在原文位置，方便回溯；三是"先汇总、确认后写回"，对应工具层的确认机制——写操作不传 confirmed 参数就只返回预览，不会直接动文档。

Claude Code 的连接注册一次就够：

```bash
claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp
```

连上后有 46 个文档工具可用：长合同先 document_meta 看字数、段数和是否建议分块，超长就用 document_chunks 分页读；document_locate 按条款名定位锚点；最后 document_add_comment 写批注，必须显式 confirmed:true 才落盘。Cursor 和 Codex CLI 填同一个地址，写法类似。

## 第四步：人工复核，该谁拍板谁拍板

批注出来之后才是正事。AI 标"缺违约责任条款"，是真缺，还是写在补充协议里了？AI 标"履行期限表述异常"，是异常，还是行业惯例？这些判断它做不了，也不该做。我们的分工线很清楚：机器负责一个不漏地圈出来，法务负责一条一条定性。缺项扫描是预筛辅助，不替代人工法务审查，更不替代外部律师意见——这句话建议直接写进部门的流程文件，先把责任边界立住。另外建议把每次扫描的确认清单留档：哪一版查过、谁确认的、当时补了什么，事后追溯有据可查。

## 适用场景与一点体会

这套打法适合三类人：合同量大的法务与合规岗、管模板的合同管理部门、用印前做最后终检的经办人，乙方视角的合同起草自查同样适用。用印前终检这道工序，以前拼的是耐心，现在拼的是规则——把"要查什么"写成清单、写成提示词，机器替你不跳行地执行，人的注意力留给真正吃经验的地方。合同审查里最不值钱的劳动，就该交给最不知疲倦的那个"实习生"。
