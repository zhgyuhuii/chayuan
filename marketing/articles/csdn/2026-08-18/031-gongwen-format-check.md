# 标题、主送、落款缺项：党政机关公文格式 AI 自检清单

周五下午四点半，盖章前最后一遍核对。办公室小王那份通知我还是看漏了一处：附件说明的写法不对，被办公室主任用铅笔圈了出来。这种错不是不会，是累。公文格式国标里要素十几个，一份材料从拟稿、核稿到签发要过好几道手，每道手都在赶时间。今年上半年起，我把这套核对活交给了察元AI文档助手——一个跑在 WPS 文字里的开源加载项，背后是只监听本机的 MCP 服务——让机器先筛一遍缺项，人再做最后判断。都说政务大模型落地难，我看落地点不在多大的模型，而在这种十分钟的琐碎活上。基层减负减到文秘头上，最先该减的就是这种重复核对。

我的自检清单八条，条条都是退回件教出来的。

**一、标题三要素。** 发文机关、事由、文种，缺一项都是硬伤。用加载项内置的"表单智能提取"助手——它本来就是给合同、公文抽字段输出 JSON 的——让它把标题拆开看，输出里缺哪段一目了然。

**二、主送机关。** 通知没了主送，受文对象就是悬空的；请示的主送只能有一个。同样按字段抽取，抽出来是空的，就把批注钉在标题下方，拟稿人一打开文档就看得见。

**三、成文日期。** 该写全还是简写、署名和日期的相对位置，最容易在改稿改到最后一版时被覆盖掉。这一项我放在盖章当天再查一次，因为日期常常当天才定。

**四、签发人。** 上行文要标签发人，平件最常忘。AI 不判断该谁签，但能提醒"这份是上行文，没看到签发人标识"。

**五、附件说明。** 正文之后、发文机关署名之前，附件序号和名称要对得上附件本身。多文档交叉检查在这个环节最值钱——正文写"附件：实施方案"、附件封面却是"实施细则"这种错，单看一份永远发现不了。

**六、序号层级。** "一、（一）、1."三层往下走，乱一层全文体例就散了。加载项里有个"检查段落序号格式"助手，一键扫全文，这个我后面单独写一篇细说。

**七、数字与标点。** 正文里的数字和表格里的合计对不对，百分比加起来是不是一百。让 AI 核对数表与正文数字是否一致，勾稽错误逃不掉。

**八、落款与版记。** 发文机关署名、成文日期、印章——盖章之前的最后关口，也是领导催得最急的关口。这里出错，重打的不是一页纸，是整套签发流程。

操作上我固定两步。第一步，先让 AI 出问题清单不动正文：

```
先跑一遍校对（dryRun），汇总问题列表，不要先改正文；我确认后再写成批注
```

第二步，人工过目后把确认的问题转成批注，钉在原文位置，交拟稿人自己改，改一条消一条。终检用这条兜底：

```
帮我做发布前终检：错别字、标点、数字前后一致性、表格与正文是否一致；全部用批注输出；最后给我一份问题分级摘要（严重/一般/建议）
```

分级摘要这条我尤其推荐。以前跟领导口头汇报"大概没问题"，现在能拿着一张三档问题清单去：哪条是硬伤、哪条是建议，一句说清，领导批得也快。

多人协作时这套清单还有个用法：拟稿人自查跑一遍，核稿人复核再跑一遍，两遍结果都以批注留痕，谁查过、查出了什么，文档里看得见。我们科室现在的核稿习惯是机器清单打头、人眼压阵，格式类的退回件比往年明显少了。

要说清单的边界，也得讲清楚：它查的是内容层要素——标题、主送、落款、附件说明这些"文字里写着"的项；版式层面的东西，比如页边距、字号、版头位置，那是排版模板的事，模板对了它就对了，AI 替你查不了也不用查。所以我的分工是：模板管版式，AI 管要素，人管签字，三层各干各的。另外加载项里二十多个内置助手，拼写语法检查、生成摘要、提炼关键词是通用款，表单智能提取和文档审计是公文场景的专用款，按需取用就行，不必个个都点开试。

最后几句实话。格式自检是辅助，AI 抽字段、圈缺项都可能有漏有误，核稿签字的责任还在人；涉密文稿走这套流程之前，先确认部署环境合规（保密场景后面几篇单独讲）。工具本身安装不难，一行 PowerShell 的事：

```powershell
& {[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$w=New-Object Net.WebClient;$w.Encoding=[Text.Encoding]::UTF8;$s=$w.DownloadString('https://gitee.com/cloudshd/chayuan-wps-releases/raw/master/scripts/install-wps-skill-chayuan.ps1');if($s.Length -and $s[0]-eq[char]0xFEFF){$s=$s.Substring(1)};& ([scriptblock]::Create($s)) -Fetch}
```

跑完 WPS 打开即用。清单在手上，机器筛一遍，人守住最后一眼——我觉得这才是人机分工该有的样子。
