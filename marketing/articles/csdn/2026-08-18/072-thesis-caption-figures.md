# 图表编号与题注错位：caption.list 帮你一个个抓出来

改过大论文的都碰过这种事：第三章删了一张图，后面所有"图3-X"的编号全错位；正文里写"如图4-3所示"，翻到第四章根本没有4-3，因为那张表挪去了附录；更隐蔽的是重号——两个图都叫"图5-2"，自己看的时候压根注意不到。还有反过来的一种：题注还在，图被删了，留下一个孤零零的"图2-4 图像分割结果"飘在文档里。盲审老师对这种机械性错误的容忍度极低：编号都乱成这样，数据还能信吗？委屈，但没处说理，因为逐个核对几百条题注确实是反人类的活。

这篇按教程走一遍，用察元AI文档助手的题注枚举能力把这件事变成五分钟的工作。它有两个专门对付题注和域的工具：caption 负责题注，其中 caption.list 把全文题注逐条枚举出来；field 负责域，field.list 能查文档里用了哪些域，还能构造 SEQ 自动编号域。下面五步走。

## 第一步：下载安装

Windows 用户开 PowerShell，粘贴这一行回车：

```powershell
& {[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$w=New-Object Net.WebClient;$w.Encoding=[Text.Encoding]::UTF8;$s=$w.DownloadString('https://gitee.com/cloudshd/chayuan-wps-releases/raw/master/scripts/install-wps-skill-chayuan.ps1');if($s.Length -and $s[0]-eq[char]0xFEFF){$s=$s.Substring(1)};& ([scriptblock]::Create($s)) -Fetch}
```

脚本一条龙：装 WPS 加载项、装本机 MCP 服务并注册自启、跑四级体检、往 Claude/Cursor/Codex 投放技能文件，全程不需要 Node.js。装完重启 WPS，加载项出现在功能区就能用。macOS 和 Linux 有一行 curl 版本，官网文档里复制即可。

## 第二步：配置连接

用 Claude Code 的话，终端一条命令注册：

```bash
claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp
```

Cursor 用户在设置里加 MCP 服务填同一个地址即可。服务只监听本机回环地址，论文不出网。

## 第三步：验证

浏览器打开 `http://127.0.0.1:62588/healthz`，返回 `online` 就是通的。刷不出来先看 WPS 开了没有：智能体那头如果报 WPS_AGENT_OFFLINE，意思就是 WPS 或者加载项还没连上服务，把 WPS 拉起来重新打开文档即可，一般不用重启电脑。

## 第四步：测试

拿正文试一句：

```
读当前文档的元信息，报告标题、字数和段落数
```

答对了再上论文，别拿三十万字的学位论文当第一个测试对象，这是使用所有 AI 工具的通用规矩。

## 第五步：正式使用

先枚举题注。WPS 里打开论文，对智能体说：

```
枚举全文所有图表题注，按出现顺序列出编号、类型和题注文字，检查编号是否连续、有无重号跳号
```

caption.list 会把每条题注的编号、类型（图还是表）、题注文字列成清单。跳号重号一眼就能看出来，比人肉翻页强在它不会累，也不会看串行。

再对照正文引用：

```
把正文里所有"图X-X、表X-X"的引用逐个找出来，与题注清单对照，对不上的用批注标出
```

引用悬空（正文引了一个不存在的编号）、题注错位（编号和章节对不上）、孤魂题注（图删了题注没删），这几类问题在这一步全部现形。批注会钉在具体位置上，改不改、怎么改，人说了算。写批注的操作需要显式确认才会落盘，这也是个安全垫。

两张额外的顺路检查。一是题注内容与图表是否对得上：编号没错位、但题注文字写反了（图的题注配给了表）这种低级事故，对着清单扫一遍标题关键词就能抓出来；图多且没配题注的，还有图像枚举工具能补出每张图的替代文字和前后文，缺题注的图一并列给你。二是长表格跨页：几十行的数据表翻页后没了表头，评委对着第二页的裸数据发呆，批量能力里有长表设置重复表头，顺手做了。

想更省心的话，让题注从一开始就用域来编号：field 工具可以构造 SEQ 域，插一张图删一张图，编号自动重排，正文里的交叉引用用域引用跟着走，错位从根上就少了。已经在写的新稿建议直接上域；改到后期的旧稿，先用上面的枚举对照法清一遍存量问题更现实。

## 边界与适配

机器抓的是"编号对不上"这种一致性问题，题注文字写得规不规范（图题在不在下方、表题在不在上方、中英文对照格式）属于学校模板的管辖范围，最终对照模板人工过一遍。顺带一提，察元是独立的第三方加载项，和 WPS 自带的 WPS AI 是两回事，互相独立、可以共存。适合的人群很清楚：盲审送审前的毕业论文作者、图表密集的工科论文、以及替学生做格式预检的导师秘书——几百条题注的五分钟和三小时，差的就是这一条提示词。
