# 图片的 alt、环绕方式、前后文：image.list 增强读法

去年我们组接手一份三百多页的产品手册，插图两百多张。领导提了仨要求：做一遍无障碍检查，缺 alt 的补上；把版式不齐的图理顺；列一份图片清单归档。两个实习生翻了一个星期，翻到眼花还是漏了不少。今年同样的活儿，我用察元AI文档助手的 image.list 工具，接上 Claude Code，十几分钟出全量清单。这篇文章就把这套"读图"的用法完整过一遍。

先把背景铺一下。察元是跑在 WPS 文字里的智能加载项，加一个本机 MCP 文档智能体服务，对外提供 46 个文档工具。Claude Code、Codex CLI、Cursor 这类外部智能体通过 MCP 直连之后，就能真的"翻开"你的文档干活，而不是让你来回复制粘贴。AI Agent 办公落地喊了一年，落到文档上，第一件事就是让智能体能读到文档的结构化信息——图片的元信息，恰恰是其中最容易被忽略的一块。

## image.list 读的是元信息，不是看图

这一点必须先说清，不然容易期望错位。image.list 不是图像内容识别，它读的是每张图在文档里的"档案"：替换文字（alt）是什么、环绕方式（wrap）是哪一种、图片前后各接了什么文字。至于图里画了什么，那是多模态大模型的事。但做排版治理和无障碍检查，恰恰是这份档案最值钱——一张图会不会压住正文，看环绕方式就知道；一张图该配什么 alt，看前后文就有线索。

## 三步把环境搭起来

第一步，装察元。Windows 一行 PowerShell 就够了，脚本会自动装好 WPS 加载项、本机 MCP 服务和技能文件，MCP 服务还会注册开机自启，全程不需要另装 Node.js。

```powershell
& {[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$w=New-Object Net.WebClient;$w.Encoding=[Text.Encoding]::UTF8;$s=$w.DownloadString('https://gitee.com/cloudshd/chayuan-wps-releases/raw/master/scripts/install-wps-skill-chayuan.ps1');if($s.Length -and $s[0]-eq[char]0xFEFF){$s=$s.Substring(1)};& ([scriptblock]::Create($s)) -Fetch}
```

第二步，给 Claude Code 注册 MCP 服务，地址是本机的 62588 端口：

```bash
claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp
```

第三步，验证链路。访问 http://127.0.0.1:62588/healthz，返回 online 就说明 WPS、加载项、MCP 服务整条链都通了。服务只监听本机回环地址，文档内容不出网，这一点在内网环境里尤其要紧。

## 三个字段，对应三类问题

alt 字段。读屏软件靠 alt 把图"念"出来，无障碍检查第一项就是查它。alt 为空、alt 写成"图片1"这种占位符、alt 与前后文完全对不上，都算问题。两百张图靠人工核对，漏检几乎是必然；让智能体拉全量清单逐条比对，才有底数。

wrap 字段。嵌入式、四周型、衬于文字下方、浮于文字上方，各有各的用途，但一份正式手册里混进几张"浮于文字上方"的图，打印时压住正文、转 PDF 时错位，这种事故我见过不止一次。按环绕方式分组统计，异常项一眼就冒出来。

前后文字段。图片不是孤岛，它前后那两段往往就是语境。判断一张截图该不该删、挪到哪儿、alt 该怎么写，都得看前后文。对智能体来说，这个字段等于给每张图配了一个"定位锚"，后续写批注、做替换，都不至于张冠李戴。

## 两条提示词，直接抄走

摸底盘点用这条：

`列出文档中所有图片，输出一张表格：序号、alt 文本、环绕方式、前后文摘要，并把 alt 为空或明显是占位符的图单独标出来`

定点排查用这条：

`找出环绕方式为"浮于文字上方"的图片，结合每张图的前后文判断是否可能遮挡正文，把结论整理成一份按风险排序的清单`

跑完第一条，全量底数就有了；第二条把版式隐患直接定位到具体图片。后面要补 alt、改环绕，再让智能体按清单逐条处理，人工只管抽查复核。

## 边界与适用人群

alt 的建议文案可以让 AI 起草，但一张图到底想表达什么，还得懂业务的人拍板；工具给的是线索和底数，不是终审结论。这套读法适合的典型场景：手册维护、标书排版、无障碍合规检查、送审前的图片清理。另外，加载项里还有一套图像批量的"治"能力——导出或删除全部图像、统一或清除格式、图像题注，和 image.list 的"读"正好凑成组合拳，下一篇展开讲。
