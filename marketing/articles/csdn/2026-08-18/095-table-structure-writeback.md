# 口语说"在哪插"就插行插列：表格结构写回实测

周六上午，销售把一张四十多行的报价单甩过来：在"合计"上面加一行"小计"，"备注"左边加一列"交期"，中午前要。搁以前这是鼠标活——找到合计行、右键、插入行，再到表头找备注列、插入列，最后再核对格式没乱。这次我没碰鼠标，开了 Claude Code，对着文档说了两句话，活干完了。这篇把过程和背后的机制摊开讲。

## 先把环境说清

察元AI文档助手是"WPS 加载项加本机 MCP 服务"的组合，Windows 上一行 PowerShell 脚本装完：

```powershell
& {[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$w=New-Object Net.WebClient;$w.Encoding=[Text.Encoding]::UTF8;$s=$w.DownloadString('https://gitee.com/cloudshd/chayuan-wps-releases/raw/master/scripts/install-wps-skill-chayuan.ps1');if($s.Length -and $s[0]-eq[char]0xFEFF){$s=$s.Substring(1)};& ([scriptblock]::Create($s)) -Fetch}
```

这条脚本背后是一条完整的链路：装加载项（放进 WPS 的加载项目录并注册，WPS 打开即加载）、部署 MCP 服务并注册开机自启、跑一轮四级体检从加载项文件到健康检查、握手、桥接工具逐层确认，最后把技能文件投放到 Claude、Cursor 这些工具里。下载源有多个，Gitee 不通就自动回退，文件全程做哈希强校验，办公内网环境也稳。macOS 和 Linux 用户换成一行 curl 命令，同样一步到位。装完给 Claude Code 注册服务：

```
claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp
```

服务只监听本机回环地址，访问健康检查接口返回 online，就说明链路是通的。服务本身是单文件程序，不需要先装 Node.js，这点对办公机很友好。用 Cursor 的同事在项目配置里加同一段 JSON，用 Codex 的在配置文件里填同一个服务地址，都是一分钟的事——服务是同一套，智能体随便换。

## 实测一：在"合计"行上面插一行

```
在"合计"行上面插入一行，列结构和上一行一致
```

指令发出去，AI 没有直接动手，先做了切片读——把表头和列位置读出来，定位"合计"所在的行号，然后才调用表格工具的 row_insert，按坐标插入一行，列结构与上一行保持一致。前后十几秒。

这里值得拆一下机制：表格域一共十二个 action，插行插列的 row_insert 和 column_insert 只认显式坐标，不认"在哪插"这种口语。口语到坐标的翻译由 AI 完成——它先用 header_read、column_read 这类切片读动作把锚点找出来，再把锚点换算成行列坐标交给工具执行。翻译归模型，执行归工具，坐标错了工具不会将就。

## 实测二：在"备注"列左边插一列

```
在"备注"列左边插入一列，整列留空
```

column_insert 同理：AI 先定位"备注"是第几列，再按坐标在它左边插列。算一笔账：以前的流程是找到合计行、右键插行、核对格式，再滚到表头找备注列、右键插列、再核对一遍，中间放大缩小来回定位，前后十分钟；现在是两句话加两次回车。但省时间还不是重点，重点是出错的面变小了——鼠标点错行、插到合计行下面这种事故，从流程上就不存在了，因为坐标是显式的，插哪就是哪，每一次执行都白纸黑字。

## 为什么这个分工重要

这正是 MCP 工具调用机制的价值所在。Claude Code、Codex、Cursor 这些智能体通过 MCP 直连 WPS 文档，工具端保持"笨而准"：只按显式坐标执行结构操作；智能端负责理解"合计上面""备注左边"这类人话。工具越"笨"，结果越可预期——你不用担心 AI 理解偏了还硬执行，坐标对不上它会报锚点校验失败，而不是悄悄插错位置。对表格这种结构化数据来说，可预期比聪明值钱，一张插错行的报价单流出去，聪明救不回来。

## 适用与边界

适合谁：常年维护报价单、报表、台账的岗位，以及在办公室试点 Agent 的技术同事——这是演示"AI 真的在干活"最直观的场景之一，插没插、插在哪，肉眼可查。边界提醒：插行插列是结构性改动，动手前先让 AI 另存一份，保存接口支持另存为，正式对外的表格一定留副本；表格里若有敏感数据，先把模型端点配到内网再动结构，这跟选什么工具一样重要。

说人话就能插行插列，看着像魔法，拆开是翻译和执行两层各干各的活。这套分工，比一个"什么都能干"的智能按钮靠谱得多。
