# 察元AI文档助手 4.1.2：那个把 MCP 服务干掉的黑窗终于没了

做信息科的人应该都遇到过这种事。局里上了 WPS 智能加载项，外接 Claude Code 用得好好的，突然有人跑来问 AI 怎么连不上了。远程过去一看，服务没了。追问半天才知道，上午有人看到桌面弹了个黑色窗口，顺手点了关闭。不能怪用户，谁看到一个不明黑窗不想关掉它，可那窗口背后就是服务进程。

今天察元AI文档助手发的 4.1.2 把这个坑从根上填了。

下载安装。官网 aidooo.com 下载 Windows 安装器，双击装完重启 WPS。已有用户重跑官网那行 PowerShell 一行命令覆盖升级即可，旧配置不动。

配置。终端执行 claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp，智能体接入完成，地址是本机回环，不需要 token。

验证。浏览器打开 http://127.0.0.1:62588/healthz，返回 ok 服务就是活的。升级前后各看一眼，对比着心里踏实。

测试。先别干活，来一句：报告当前文档的连接状态。它能答上来，说明 WPS 到服务的链路通了。

使用。这次的改动就在使用体验里：手动脚本、开机自启、安装器首启、加载项里的启动按钮，全部改成后台隐藏拉起，一个窗口都不弹。设置页那个诊断按钮以前服务掉了只会报失败，现在会自己把服务拉回来。

留两条日常提示词。
一、对当前文档做错别字校对，只列清单不改正文。
二、检查本机 MCP 服务状态，掉线的话自动拉起并报告结果。

干运维的都明白，用户不因为你服务做得好来表扬你，只会在挂了的时候找你。把黑窗这种小而天天坑人的细节处理掉，比多加十个功能实在。这次升级，值得。
