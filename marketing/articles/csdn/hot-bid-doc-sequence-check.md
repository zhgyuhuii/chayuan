# 察元AI文档助手查标书：差一个序号就废标的事故，先让机器筛一遍

做过投标的都知道，废标理由里最冤的是形式审查没过。编号跳了，第三条下面直接是第五条。目录和正文对不上。同一列数字有的带百分号有的不带。技术方案一分没丢，倒在这种地方，气笑了也来不及。

公司管标书的同事以前用三个人轮流读三遍的办法，效果一般，人读长文档注意力会掉，跳号恰恰出在中后段。后来这一步交给了察元AI文档助手。

下载安装。官网 aidooo.com 下载 Windows 安装器，双击装完重启 WPS。标书常在保密机上做，这个加载项本机运行，不往外传正文。

配置。终端执行 claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp，接上智能体。

验证。浏览器打开 http://127.0.0.1:62588/healthz，返回 ok 就是通的。

测试。先拿一份旧标书试水，说一句：读当前文档前两段，告诉我文档结构。它答得上来，说明几百页的文档它能正常分块读。

使用。WPS 打开标书，指令就一句：核对全文编号连续性，条款号、段落序号、图表编号都查，跳号、重号、格式不一致逐条列出。它分块读完几百页，交回带位置的问题清单，我们按清单改，改完让它复查。查序号是纯规则比对，机器不累也不跳行，比人稳。结果全挂批注，标书正文没被直接动过，每一版留底不受影响。

提示词常用三条。
一、核对全文编号连续性，列出跳号重号和格式不一致。
二、复查一遍，确认上一轮指出的问题是否都已修复。
三、把目录条目和正文标题逐项对照，不一致的列出来。

上个月两个标，形式审查一次过。省下来的注意力留给技术响应和报价策略，那才是中标的地方。
