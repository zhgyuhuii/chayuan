# 察元AI文档助手整理审计报告：散落的数字和结论，先聚拢再人工拍板

写审计报告的同仁都有这个体会。正文六十多页，结论散在各章，基本情况一个数，问题部分一个数，建议里又引用一个数。领导最爱问，这几个数对得上吗，结论归纳成一页给我。

以前是开着计算器来回滚屏，抄在便签上再对，一个熟练的人大半天。现在用察元AI文档助手，流程是这样。

下载安装。官网 aidooo.com 下载安装器，双击装完重启 WPS。内网机器用离线包，拷进去装一样。

配置。终端执行 claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp，一条命令接上智能体。审计环境不放心的，模型可以指到内网部署的端点，正文不出域。

验证。浏览器打开 http://127.0.0.1:62588/healthz，返回 ok 即通。

测试。先说：读当前文档的元信息，报告标题、段落数、字数。答对了再上报告。

使用。WPS 打开报告，给两句话。第一句，把全文关键数据按出现位置列出来，前后不一致的标出来。第二句，把各章节的结论和风险点提取归类，先给我清单，确认后追加到文末。它分块读完，交回数据对照清单和结论汇总草稿，你人工核过口径，再让它追加到报告末尾当提要。

提示词记三条。
一、列出全文关键数据及每次出现的位置，同一指标前后不一致的高亮。
二、把散在各章节的结论与风险按问题归类输出，不动正文。
三、把上面提取的结论追加到文末，格式与正文一致，完成后报告追加位置。

注意点也直说。数字勾稽它比你细，但统计口径改过几轮它不知道，定性轻重更得人把关。机器管找，人管定，各干各的。报告的质量从来不在打字速度，在想清楚问题定什么性。
