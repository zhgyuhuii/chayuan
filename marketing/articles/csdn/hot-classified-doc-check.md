# 察元AI文档助手做脱密检查：材料上报前十分钟的本机筛查

管过保密的人都知道，最怕的不是大错，是小疏漏。材料明明定不了密，里面有人员手机号、内部项目编号、涉密场所名称，报上去就是一次通报。人工查靠责任心，可几十页看三遍，总有一遍走眼。公网大模型想都别想，把待脱密材料粘进外网对话框，这一步本身就违规。

第三条路是用察元AI文档助手在本机做筛查，全程不外发。

下载安装。官网 aidooo.com 下载安装器，拷到工作机安装，双击装完重启 WPS。完全离线的环境用离线包，一样装。

配置。终端执行 claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp。这个地址只监听本机回环，外网碰不到。模型端建议指到内网部署，正文一个字不出域。

验证。浏览器打开 http://127.0.0.1:62588/healthz，返回 ok 服务就绪。

测试。随便开个空白文档，说：报告当前文档状态。能应答说明链路通，再换正式材料。

使用。WPS 打开待报材料，对智能体说：对当前文档做敏感信息筛查，手机号、证件号、内部编号、涉密词，按风险分级列清单，先给我看。它在本机分块读完，交回分级清单，每条是原文哪几个字、什么类别、风险高不高。确认后可以让它挂成批注留档，也可以让它按规则做脱密处理，密码可还原，不是一锤子买卖。

提示词常用三条。
一、对当前文档做敏感信息筛查，按类别和风险等级列清单，只列不改。
二、把确认的敏感项逐条挂批注，注明类别。
三、对清单中的手机号做脱密处理，完成后报告处理条数。

必须强调，这类检查是辅助，不替代定密程序，密级由定密责任人按制度定。工具的价值是把人眼会漏的机械项先筛出来。上报前十分钟跑一遍，清单留档，出过事的人都知道这两样关键时刻能说明什么。
