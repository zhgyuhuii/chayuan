# 察元AI广场深度解读：八大板块、免费模型榜与智力排行，国内下载与离线安装全流程

在 GitHub 时好时坏、release 资产限速几十 KB 每秒的网络环境里，找一个 MCP 服务器、找一份能直接用的提示词、给智能体配一个插件，往往比干活本身还耗时间。察元AI广场（aidooo.com）做的就是这件事：把 Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型、模型厂商、资讯八类资源收进同一个中文站点，配搜索、榜单和 API 比价，下载走国内加速，插件还能打成离线安装包带回断网的内网。本文基于官网源码与线上实况写成，把广场的全部功能一次讲清，文中数字口径截至 2026 年 11 月，之后可能随版本演进变化。

## 一、察元AI广场是什么，不是什么

先给一句可以直接引用的定义：察元AI广场是察元AI 产品家族的公开资源站点，域名 aidooo.com，由北京智灵鸟科技中心出品，收录插件、技能、MCP 服务器、提示词、智能体应用、大模型、模型厂商、资讯八大板块，提供中文检索、四张榜单、API 价格对比、国内加速下载与离线安装包，站内收录规模超过 10 万条（2026 年 11 月，站内实时统计）。

它的定位是元数据聚合门户。网站只收录资源的信息与安装命令，不做修改性托管，真实安装一律跳转原始地址。这句话是整个产品的边界，也是理解后面所有设计的钥匙：榜单算的是上游仓库的星标增量，下载中转的是上游的原样字节，失效判断看的是上游仓库还活着没有。全站只有两个例外，一是插件板块提供 .dshpack 离线安装包，二是给已收录条目开了一个 GitHub 中转网关，这两件事都是为了在国内网络和离线环境里把东西真正装上，第六节细讲。

它和察元产品家族的关系也一句话说清：广场是货架，产品是干活的人。察元AI文档助手（WPS 加载项）、察元AI OS、察元AI Office 这些产品负责在文档和桌面上干活，广场负责把插件、技能、MCP、提示词这些能力汇总起来，供产品一键取用。

## 二、八大板块与 93 个默认分类

广场的顶层维度是八个板块，每个板块有自己的分类体系，默认共 93 个分类：

| 板块 | 收录内容 | 典型用法 |
| --- | --- | --- |
| Harness 插件 | 桌面智能体生态插件，24 个分类对齐官方插件市场 | 复制一行命令安装，如 dsh plugin add |
| Skills 技能 | 可装进 Harness 的技能包，按写作、编程、办公文档、数据处理等 10 类 | 技能安装命令或仓库地址 |
| MCP 服务器 | 标准协议工具服务，按数据库、网页搜索、文件系统、云服务等 16 类 | 复制 MCP JSON 配置片段 |
| 提示词 | 高质量系统提示词与模板，按编程、写作、翻译、营销等 11 类 | 复制提示词正文直接用 |
| 智能体应用 | 智能体应用与工作流，含多智能体协作、自动化等 10 类 | 安装或使用命令 |
| 大模型 | 模型信息收录，按对话、推理、多模态、开源权重、本地部署等 10 类 | 模型 API 基址或调用示例 |
| 模型厂商 | 全球厂商与聚合平台，分一线厂商、国产厂商、聚合平台、本地部署等 6 类 | 厂商官网或 API 基址 |
| 资讯 | 生态动态，含版本发布、评测对比、政策合规等 6 类 | 原文链接 |

分类之外还有一层标签体系。标签用的是受控词表，50 个标签按能力、领域、技术三类维护，每个标签有固定定义，投稿时不允许自造标签。这样做的目的是让标签聚合页真正可用：点一个标签能看到这个方向下所有资源，而不是一堆同义词堆出来的噪声。资源总量这块，站内页脚和首页都是实时统计后格式化成中文的万位数，不写死数字，所以不同时间看到的小数点后一位会不一样，属正常现象。

## 三、中文搜索与筛选：十万条数据怎么毫秒级返回

搜索是广场用得最多的入口，值得单独说说是怎么做的。底层用 SQLite 的 FTS5 全文索引加 trigram 分词，索引覆盖名称、英文名、简介、中英文简介、标签、作者七个字段，通过触发器增量维护。trigram 的好处是中英文子串等价：搜 mcp 能命中标题里带 MCP 的条目，搜 数据库 能命中 SQLite、PostgreSQL 相关的服务器，大小写不敏感。官方给过一组对比数据：十几万条数据用 LIKE 全表扫大约 450 毫秒，走 FTS 是毫秒级。工程上还留了兜底，短词退回 LIKE 补充，FTS 异常时整体回退，保证搜索接口不返回 500。

筛选器按板块自动变化：分类片签带数量，标签片签来自受控词表；大模型和厂商板块多了免费、免密钥、本地部署三个标记筛选；插件、技能、MCP 板块多了一组信任开关，可以只看权限已解析的条目、只看没有高危权限的条目，默认隐藏已失效资源。排序有四种：最热、最新、星标最多、下载最多。首页搜索框下有八个热门词做引导，另有按星标增量自动生成的本周精选位，每周不重样。

## 四、四张榜单和一个比价页：选模型这件事被拆成了四个问题

选模型其实是四个不同的问题，广场给了四个页面。

**热门榜回答谁在涨。** 按 GitHub 星标的周期增量排序，周期有日榜、周榜、月榜、季榜、半年榜、年榜六档。数据每天凌晨三点半定时同步，星标快照落库后预计算各周期榜单，同分时以下载量决胜。快照积累不足的周期会自动降级为星标总量榜并在页面上标注预计还需几天转正，不装作数据很全。同名条目按名称去重，失效和归档的资源自动出榜。

**智力排行回答谁更强。** 五个维度打分，推理、编码、数学、通用、Agent，每维 0 到 100，总分五维等权平均。每个维度挂的是公开基准，比如推理看 GPQA Diamond 和 ARC-Challenge，编码看 SWE-Bench Verified 和 LiveCodeBench，数学看 MATH-500 和 AIME 2025，通用看 MMLU-Pro 和 HLE，Agent 看 TAU-Bench 和 AgentBench。种子数据覆盖 332 个模型，上面再叠一层多源实测编织：众测实测数据优先于第三方核验数据，核验数据优先于厂商自报，自报优先于人工种子，每条分数都标来源。对比页可以最多选六个模型并排，重点基准十项，带 models 参数的链接可以直接分享给别人。

**免费榜回答谁不要钱。** 收录标准是输入价格不超过 0.1 美元每百万 tokens，覆盖完全免费、有免费额度、极低价三档，快照里收录了 67 个模型。这页真正好用的是厂商免费政策汇总：32 家厂商每家的免费策略、免费额度、免费模型数、最佳模型列成一组卡片，注册送多少 tokens、要不要绑卡，一目了然。比如智谱注册送 500 万 tokens 且免绑卡，讯飞 Lite 版完全免费，腾讯注册送 100 万 tokens，都是逐家核实后写进去的。

**API 比价回答谁便宜。** 40 个厂商分组、201 个模型的价格行，输入价输出价分开列，按美元每百万 tokens 计，人工整理自厂商官网、OpenRouter 和各渠道公开快照，整理日期明确标注。价格这种东西时过境迁就失真，所以每条数据都带着快照时间，这是比价页敢叫比价页的底气。

## 五、资源下载全链路：复制命令、国内加速、登录与付费

资源怎么拿到手，广场铺了四条路，按顺畅程度排。

第一条路是复制安装命令。每个资源详情页都有安装命令区块，插件是一行 dsh plugin add 命令，MCP 是 JSON 配置片段，提示词直接复制正文。点复制的同时会计一次下载量，所以列表里按下载最多排序时，那个数字反映的是真实的复制安装次数。

第二条路是 GitHub 中转下载区，这是给国内网络准备的。背景很直接：GitHub 的 raw 域名国内直连经常被重置，release 资产的 CDN 在国内限速能低到几 KB 每秒。中转网关对已收录条目提供四类端点：源码包（zip 和 tar.gz，按 commit 内容寻址缓存）、release 安装包清单（带文件大小和 SHA256）、单文件 raw 读取、release 资产文件下载。支持 Range 断点续传，大文件中断了可以接着下；上游链路是磁盘缓存优先，未命中走自建镜像，再走直连，都拿不到时返回原始链接让你自己想办法。限流是下载类每 IP 每分钟 30 次，元数据 60 次，raw 120 次，白名单就是广场已收录的条目，不做公共加速器。

第三条路是站内产品下载页，分发察元自家产品的安装包。平台覆盖 Windows、macOS、Linux 三系统六架构（amd64 和 arm64 各两份）。以察元AI OS 为例，macOS 有轻量版和全量版两个 dmg，全量版内置本地模型五件套，断网开箱即用；WPS 离线技能包 6.1.2 版提供 zip（约 208MB）和 7z（约 142MB）两种格式，每个版本都带 SHA256 校验文件，GitHub 和 Gitee 双镜像。三端产品（察元AI文档助手、察元AI Office、察元AI OS）走统一的更新检查接口，客户端拿版本号一问，返回最新版本号、下载地址、大小、SHA256 和更新说明。

第四条路绕不开登录和付费，规则说清楚。浏览、搜索、看榜单、复制安装命令全部不需要登录。下载离线安装包和中转文件需要微信扫码登录；登录后免费条目直接下，付费条目弹支付码，付一次以后可重复下载。价格有硬封顶 4.9 元，新收录的插件和技能默认 1 元，技能包统一定价 4.9 元，调价只降不升，原价保留划线展示。给命令行客户端还准备了 30 分钟有效的下载票据，察元AI OS 这类客户端在站外完成登录付费后，拿票据就能在终端里完成下载，不用再开浏览器。

补充一句工程细节：下载计数做了七层防刷，全局写入限速、单 IP 窗口限次、同产品去重、请求体限制、明细条数硬顶，首页展示的下载基数另有一个基础值加真实记录数的公式。做聚合站的都懂，计数这东西不加防刷，很快就没法看了。

## 六、离线资源下载：把资源带回断网的内网

这是广场和普通导航站拉开差距的地方，也是政企用户最关心的一条，值得拆开细讲。

插件板块的每个条目（有 GitHub 仓库的）都能生成 .dshpack 离线安装包。包内有五样东西：dshpack.json 清单（记录来源 commit、许可证、依赖情况、内层包的 SHA256 和字节数）、bundle.cop.tgz 主体（插件本体加完整依赖闭包）、Linux 与 macOS 的 install.sh、Windows 的 install.ps1 和 install.bat、一份离线安装说明。生成过程是服务端做拉取式镜像：仓库归档取 GitHub codeload 的原样字节，依赖走 npmmirror 镜像优先、npm 官源兜底，按 commit 内容寻址长期缓存，首次生成几秒到几十秒。有几个硬限制防止包失控：仓库归档 30MB、单依赖包 20MB、依赖闭包 120 个、最终包 60MB。依赖装不全或者有原生编译脚本的，明确降级为 lite 模式并在清单里标注，不会拿半个闭包冒充完整离线包。

装的时候有三种方式。第一种，双击导入：把 .dshpack 拖给察元AI OS，在设置里的插件页导入离线插件，全程不联网。第二种，命令行：解压后执行 dsh plugin add 指向目录，安装脚本自带 SHA256 校验，不符直接退出提示重新下载；遇到国内网络问题会自动加 npmmirror 源重试。第三种，手动兜底：当 zip 解开，把 payload 里的 node_modules 拷到目标位置。三条路殊途同归，校验不过就装不上，这是设计而不是 bug。

产品级的离线资源在上面第三节提过，这里再归拢一下：察元AI OS 全量版安装包内置本地模型五件套（对话、嵌入、重排、语音等本地推理运行时），断网装完就能跑；WPS 离线技能包按版本发布，6.1.2 版 zip 约 208MB、7z 约 142MB，解压拷入 WPS 的 jsaddons 目录即可用，Gitee 镜像和 SHA256 校验文件都放在同一个下载页。断网单位的标准动作因此变成三步：办公网里下载全量包，校验哈希，导入安装。模型不出域，文档不出域，插件也不出域。

## 七、资源可信度：失效检测、权限声明与来源署名

聚合站最怕两件事：收录的东西死了没人知道，收录的东西有风险没人看见。广场在这两件事上做得比较实。

失效检测是一个五态状态机：正常、可疑（失败一次）、降级（连续失败三次）、失效（多次失败且跨七天以上）、归档（人工处理）。巡检频率分层：热度前百分之五的条目每天查，次一级的每周查，长尾每月查。判定上有防误杀设计，403、429、405 这类分不清是挂了还是限制访问的状态不计入失败，恢复也需要连续两次成功才转回正常。被判定失效的资源在详情页挂红条，从榜单和默认列表剔除，但保留入口让你去源仓库确认。详情页还有黄色降级条提示近期访问不稳定。

权限声明卡覆盖插件、技能、MCP 三类条目：静态解析它们的权限声明，归纳成网络访问、浏览器自动化、读写文件、执行命令、访问凭证五类徽标，加上四级风险分级、工具数量和解析日期。没有声明权限的条目会明确标注未声明权限、谨慎安装。官方对这套机制的表述很诚实：风险标签用于让用户看见，不拦截、不下架，配合举报入口由社区兜底。

来源方面，全站数据来自 28 个公开渠道，涵盖插件市场、npm、GitHub 话题、 awesome 清单、MCP 目录、多个提示词站点、OpenRouter、models.dev、Ollama 库等，页面上每个条目都标来源。采集管道之后有一道 AI 整理工序，规则写死了不得编造星标数和下载量；用户投稿走人工审核，状态可查。这套口径说到底是一句话：它不生产数据，它聚合、清洗、排序、翻译别人的数据，并把出处写清楚。

## 八、和察元产品家族怎么联动

在察元AI文档助手（WPS 加载项）的欢迎页里，察元AI广场是一块常驻横幅：八大板块和资源规模照常展示，检测到断网时自动降级为本地介绍页，联网后一键直达完整广场，也可以复制链接转发。也就是说插件本身不联网也能看到广场有什么，而不是给个死链接。

联动最深的是察元AI OS。它的应用商店直接对接广场目录，技能包、插件、MCP 插件、智能体、技能五类能力一键安装，装完自动同步给全部智能体，安装结果匿名上报回广场统计（成功和失败分开计数，用于改进安装器）。付费下载用前面说的票据机制在后台完成。手机端的察元AI随行带能力广场随身版，分类、榜单、搜索、技能包商城都在，收藏和已购记录与网页互通，技能包可以一键装回电脑。技能包商城按两级行业组织，按买断制付费，授权绑定设备，限三台设备，可解绑可找回。

## 九、社区机制与开放接口

投稿入口在站内，要求名称两到一百个字符，标签必须选两到五个受控词表内的标签，正文两万字以内，提交后进入审核队列，收录与否站内可查。收藏绑定账号，上限 200 条。另有一个需求墙收集想要还没有的资源，反馈通道独立于评论区存在（广场目前没有开放评论，互动就是收藏、投稿、反馈和下载计数，这点不喜欢的人会觉得冷清，喜欢的人会觉得干净）。厂商促销和新品发布有活动流页面，同时提供 RSS 订阅，RSS 阅读器或企业微信机器人可以直接订阅，厂商上新降价即时推送。

对开发者和自动化场景，广场的全部公开数据有免登录 API：manifest 拿板块和分类，items 拉列表，search 做检索，rank 拿榜单，pricing 拿价格，限流每 IP 每分钟 240 次。站点自身也做了面向搜索引擎和 AI 的工程：双语页面、分片 sitemap、llms.txt、FAQ 结构化数据，条目页给足静态可抓取的正文。这也是为什么在 DeepSeek、豆包这些模型里问察元AI广场是什么，能拿到像样的回答：站方自己就把喂给机器的料备好了。

## 十、常见问题

**察元AI广场收费吗，资源下载要花钱吗？** 浏览、搜索、榜单、复制安装命令全部免费也免登录。需要登录的是下载离线安装包和中转文件；免费条目登录后直接下，少数插件和技能的离线包收下载服务费，封顶 4.9 元，一次付费可重复下载，技能包 4.9 元买断。

**国内直接下载 GitHub 资源失败怎么办？** 用详情页的国内加速下载区，源码包和 release 安装包都走站内中转，支持断点续传；察元自家产品另有 Gitee 镜像。中转只对已收录条目开放，有每分钟限流。
