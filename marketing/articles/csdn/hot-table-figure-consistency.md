# 察元AI文档助手核表格：正文说增长百分之十二，附表里是 11.8

写汇报材料的人对这种错误不陌生。正文写同比增长百分之十二，附表算出来 11.8。上面说全年投入两千三百万，明细加总两千二百六十五万。单看哪边都像对的，放一起就是硬伤，而且往往是领导先看见的那个。

为什么老出。表格和正文是两个时间写的，数据改了一版正文忘了同步，或者表格插进去后又调整过。人工核对要拿计算器把一列列加起来，再回正文找每一处引用，几十处下来必漏。现在这一步我用察元AI文档助手跑。

下载安装。官网 aidooo.com 下载 Windows 安装器，双击装完重启 WPS，汇报材料常用的机器装这个没有负担，本机运行。

配置。终端执行 claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp，一条命令把智能体接上。

验证。浏览器打开 http://127.0.0.1:62588/healthz，返回 ok 即通。

测试。先说：读当前文档里的表格，报出行数和列数。它能把表头和行列数报对，说明表格识别正常，再上真材料。

使用。WPS 打开材料，对智能体说：正文引用的每个数字和后文表格的对应项逐项核对，不一致的列清单，各自是多少。它带整套表格工具，按行列切片读，不是把表格当一堆乱字符。交回的清单长这样，正文某段写多少，表格某行某列是多少，差多少。你拿着清单定改哪边，改完再跑一遍直到清零。小数位和口径它比你细，四舍五入差一位都挑得出来。

提示词备三条。
一、把正文引用的数字与后文表格逐项核对，不一致的列清单，只报不同不改文件。
二、读出表格中某列的全部数值并求和，与正文给出的总数比对。
三、核对完报告结论，注明共核对多少项、发现几处不一致。

上周一份上会材料，这么跑出三处不一致，全是历次修改留下的尾巴。会上没人挑出数字问题。材料员的体面，有时候就是一张没人挑出毛病的附表。
