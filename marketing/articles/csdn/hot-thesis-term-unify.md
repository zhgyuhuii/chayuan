# 察元AI文档助手改论文：开学前最后一周，术语统一交给机器

八月过半，师门群里开始互问论文改到哪了。改过大论文的都知道，后半程折磨人的不是内容，是一致性。同一个概念，第二章叫大语言模型，第四章简写成 LLM，摘要里又写大规模语言模型。导师批注就一行，全文术语请统一。

自己统一？几百页的文档，搜索替换不敢用，同一个词不同语境有的该换有的不该换。我今年用察元AI文档助手干的，流程写下来。

下载安装。官网 aidooo.com 下载 Windows 安装器，双击装完重启 WPS。一行命令版也行，官网文档里那行 PowerShell 粘进终端回车，自动装好。

配置。终端执行 claude mcp add --transport http chayuan-wps-mcp http://127.0.0.1:62588/mcp，回车完成。论文没定稿前不想上云端的，模型可以指本地端点。

验证。浏览器打开 http://127.0.0.1:62588/healthz，返回 ok 即通。

测试。先说：读当前文档的元信息，报告标题和章节结构。答对了再上论文正文。

使用。WPS 打开论文，第一步让智能体把全文同一概念的不同写法找出来，列出每处位置和上下文。第二步人工圈定统一到哪个写法、哪几处保留，比如参考文献标题里的不动。第三步让它按圈定逐处替换，走修订模式，每处改动留记录，导师点开就能看到改了什么、为什么改。错别字那种只提意见的走批注，术语统一这种要动正文的走修订，两不耽误。

提示词按这三步来。
一、找出全文同一概念的不同写法，列出每处位置和上下文，先不动正文。
二、按我指定的写法统一这些位置，例外清单里的保留，走修订模式。
三、复核一遍，确认没有漏改和误改，报告结果。

导师那句全文术语请统一，我半小时交了差。机器干不了研究，但这种体力活，真没必要再用人扛。
