# 察元 100 条爆款短视频脚本包 — 设计文档

- 日期：2026-06-20
- 状态：已与用户确认，进入实施
- 负责人：zhgyuhui

## 目标

为「察元（Chayuan）」AI 办公助手系统产出 **100 条爆款短视频脚本**，每条脚本与
**对应截图素材**、**SVG 封面图**用统一编号强绑定，达到「拿到即可录屏/剪辑」的程度。

## 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 视频文件 | **不产出 MP4**（本机无 ffmpeg/TTS/无头浏览器/中文字体）。交付脚本+分镜+可拍清单。 |
| 选题结构 | **爆款场景驱动**（每条 = 一个痛点场景） |
| 平台时长 | **短视频为主**，15–40s，竖屏 9:16（抖音/视频号/小红书） |
| 口吻调性 | **专业靠谱**（面向政企/专业用户，稳重可信，少网络梗） |
| 配图 | 复用仓库现有真实截图 + 每条一张 SVG 封面源文件；无 AI 文生图 |

## 目录结构（编号即对应关系）

```
chayuan-wps/marketing/
  README.md                  # 100 条总索引表
  manifest.csv               # 机器可读映射：编号→系列→场景→截图→封面→需录屏
  scripts/001-xxx.md … 100-xxx.md
  covers/001.svg … 100.svg   # 9:16 标题封面
  assets/screenshots/        # 现有截图的语义软链（W-*.png / C-*.png）
```

脚本 `001` ↔ `covers/001.svg` ↔ `manifest.csv` 第 001 行指定截图，三者编号一一对应。

## 单条脚本模板

每个 `.md` 含：编号/系列/场景标题/时长/比例(9:16)/受众/平台 →
**3秒钩子** → 痛点一句话 → **分镜表**(镜号｜时长｜画面=对应截图或录屏动作｜口播文案｜屏幕花字｜备注) →
结尾 CTA(官网 aidooo.com / 开源地址 / 下载) →
**对应素材清单**(精确到 assets/screenshots/X.png)+封面 → BGM/音效建议 → **可拍 checklist**。

- 支持本地推理：Ollama/LM Studio/Xinference/LocalAI/FastChat + OpenAI 兼容网关；云端 170+ 模型

## 执行方式

100 条独立脚本按系列分批，由并行子 agent 依统一模板与本事实基线撰写；封面 SVG 与
README 由脚本读 manifest 批量生成。不自动 commit/push（待用户明确要求）。
